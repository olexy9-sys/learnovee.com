# Publish Learnly for free with GitHub Pages

Your site will be available at:

`https://olexy9-sys.github.io/elearning-portal/`

## Publish it

1. Sign in to [GitHub](https://github.com/olexy9-sys) and create a new **public** repository named `elearning-portal`.
2. Upload every file in this folder to the repository root:
   - `index.html`
   - `styles.css`
   - `enhancements.css`
   - `script.js`
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then click **Save**.
6. Wait one or two minutes, then open `https://olexy9-sys.github.io/elearning-portal/`.

GitHub Pages will automatically serve the responsive Learnly website, including all interactive course, search, FAQ, and learner-story features.
